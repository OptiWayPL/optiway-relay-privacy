# optiway-relay-privacy

Statyczny hosting **polityki prywatności** wtyczki Chrome „OptiWay Relay" na GitHub Pages.
Publiczny URL tej strony podaje się w Chrome Web Store Developer Dashboard (pole „Privacy policy").

- Treść PL (kanoniczna): [`index.html`](index.html); wersja EN (dla review Google):
  [`en.html`](en.html). Obie samowystarczalne (bez zewnętrznych zależności), z przełącznikiem języka.
- Live: **https://optiwaypl.github.io/optiway-relay-privacy/** (Pages: branch `main`, folder `/root`).

Źródło treści (kanoniczne): repo `optiway-relay-extension`, `docs/polityka-prywatnosci.md`.
Zmiany treści nanoś tam i przenoś tutaj, żeby wersje się nie rozjechały.
